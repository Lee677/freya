CAD feature comparison

freyacad · SolidWorks · FreeCAD

freyacad is a single self-contained HTML file — roughly 9,000 lines, no build step, no framework — that runs a real B-rep CAD kernel (Open CASCADE, compiled to WebAssembly) and a Manifold-based mesh boolean engine entirely inside the browser tab. Sketch, dimension, extrude, fillet, assemble and lay out a drawing, then export STEP or STL — nothing is uploaded, nothing is installed.

How to read this: SolidWorks and FreeCAD are mature, professionally maintained packages with decades and thousands of contributor-hours behind them; freyacad is a hobby-scale project built by one person in a single file. The gaps below are real and are shown honestly — the point of this page is not to flatter freyacad but to show precisely where it stands today.

~7.10M output tokens  ·  33 items

About the cost column: an order-of-magnitude estimate of the agent output tokens needed to bring freyacad to the level of the two mature packages on that row — the implementation itself plus the iteration, the verification by measurement, and the manual update this project asks for on every user-visible change. It is not lines of code and not developer hours. Treat each figure as accurate to about a factor of two, and the large ones as assuming an existing library is integrated rather than a kernel written from scratch. A dash means freyacad is already there.

freyacad's own help.html states its gaps candidly in a "Known limits" section — this page cross-checked those claims against the source and found them accurate. The one gap the manual used to leave unnamed — that mirror and both patterns copied every shape built so far rather than the features you choose — has since been closed: all three now take a scope, and the manual describes it under “What a mirror or pattern copies”.
